QUEST — タスクRPG PoC v0.1

使い方
1. 【推奨】Windowsでは QUEST_PoC_START_Windows.bat をダブルクリックします。
   ブラウザが自動で開きます。起動した黒い画面を閉じると終了します。
   ※Pythonが必要です。別のアプリが8765番ポートを使っている場合は起動できません。
   または quest_poc.html をChrome / Edgeで直接開いても使えますが、直接開いた場合のデータ保存はブラウザの仕様に依存します。
2. 「＋ クエストを追加」を押し、名前・クリア条件・難易度を入力します。
3. 実際に完了したら「クエスト達成」からクリア条件を確認し、達成を確定します。
4. タスク完了時にXPが貯まり、完了件数が3件増えるごとに1レベル上昇します。
5. データはブラウザのローカルストレージに保存されます。
6. 定期的に「バックアップ」からJSONをエクスポートしてください。
   次回も同じURL (http://127.0.0.1:8765/quest_poc.html) で開くと、保存済みデータを読み込めます。

PoCの仕様
- クリア条件の入力必須。継続・反復業務は対象外。
- 難易度：小=10 XP、中=30 XP、大=60 XP。
- レベル：1 + floor(現在達成しているクエスト数 / 3)。ゴール機能を追加する正式版で再設計予定。
- 取消・削除時はXPとレベルを再計算。
- 成果の履歴、称号、クリア時演出あり。
- 外部サーバーへの送信なし、AI連携なし、企業別階層なし、端末間同期なし。
- 保存はブラウザや閲覧方法に依存します。別のPC・ブラウザでは自動的に引き継がれません。
- Chromeなどのブラウザデータを削除すると記録が消える場合があります。

初期テスト方法
- 「データ管理」→「サンプルクエストを3件追加する」を押すとサンプルを読み込めます。
- 3件を達成するとLv.2に上がります。

注記
このPoCは個人検証用の単一HTMLファイルです。Gitによる管理も可能です。
