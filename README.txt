QUEST — スマートフォン版 PoC v0.2
===================================

【目的】
スマホ１台で日常的にクエスト（完了条件つきのタスク）を登録・達成し、XPやレベルアップの効果を検証するためのPoC。
既存のPoC v0.1と同じデータ形式（quest-poc-v1）を使用します。ただしブラウザの保存先はアクセス先URLごとに独立しています。

【スマートフォンで使う手順：GitHub Pages】
1. GitHubで新しいリポジトリを作成（例: quest-poc）。GitHub Pagesの公開リポジトリを利用する場合、コードは公開されます。
2. このフォルダの index.html、manifest.webmanifest、service-worker.js、assets フォルダをリポジトリのルートにアップロードしコミットします。ZIPをそのまま1ファイルとしてアップロードするのではありません。
3. GitHubのリポジトリ Settings → Pages → Build and deployment → Deploy from a branch を選び、main / (root) に設定し Save。
4. 公開された https://<GitHubユーザー名>.github.io/<リポジトリ名>/ に、スマートフォンのChromeでアクセスします。
5. Chromeメニューの「アプリをインストール」または「ホーム画面に追加」からホーム画面に登録します。
6. 以後はスマホのホーム画面から使用します。初回のオンライン読み込みが成功すると、基本機能をオフラインで利用できます。

【保存・安全性】
- タスク、達成条件、XPなどはスマホのブラウザのlocalStorageにのみ保存します。GitHub Pagesのサーバーにタスク内容を保存・送信しません。
- GitHubにアップロードするのはプログラムだけです。タスクデータやバックアップJSONをリポジトリにコミットしないでください。
- GitHub Pagesの公開URL自体は他人もアクセスできますが、端末内のタスクデータは他人のブラウザには表示されません。
- ブラウザのサイトデータ消去、端末故障、OSによるデータ削除などで消失する可能性があるため、「データ管理」→「データを書き出す」でJSONバックアップを取ってください。
- URLが変わるとブラウザ保存領域も変わります。更新時は同じGitHub Pages URLを維持してください。
- 複数デバイス間の同期はありません。Google/Appleアカウントへの自動バックアップもありません。
- オフライン動作は最初のHTTPSアクセスとService Worker登録が成功した後からです。

【MVP機能】
- タスク（クエスト）登録、完了条件、難易度（10/30/60 XP）
- 達成確認、XP獲得、レベルアップ演出（3件達成ごと）
- 達成履歴、称号、取消・削除時の再計算
- JSON形式のエクスポート/インポート
- スマホ下部のナビゲーションと＋ボタン

【ローカルPC動作確認（任意）】
このフォルダで python -m http.server 8765 を実行し、http://localhost:8765/ をブラウザで開きます。
file:// から直接開く方法はスマホでは推奨しません（PWA化・保存が保証されないため）。
